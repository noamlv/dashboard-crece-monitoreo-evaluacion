# Dashboard CRECE: monitoreo y evaluación

Sitio estático para explorar el perfil de interseccionalidad de 195 beneficiarios únicos del Proyecto CRECE.

Incluye caracterización sociodemográfica, intersecciones, vulneraciones, la contribución de la implementación directa de CRECE y una sección comparativa para los resultados 1100 y 1200.

La publicación contiene únicamente resultados agregados y los recursos compilados del dashboard. Las fuentes y los microdatos no forman parte de este repositorio. Las celdas menores de cinco casos se suprimen o agrupan antes de la compilación pública.

Sitio: https://noamlv.github.io/dashboard-crece-monitoreo-evaluacion/
